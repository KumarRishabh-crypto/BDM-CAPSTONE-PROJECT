# BDM Project Description

## Project Title: **Optimizing Data Management for Efficient Operations in a Soft Drink Wholesale Store**

### Overview
This project aims to enhance operational efficiency and drive sustainable business growth for *Shiva Enterprises*, a wholesale dealer of cold drinks based in Ghazipur, Uttar Pradesh. The store faces challenges related to market competition, seasonal sales variations, and pricing strategies. Using data-driven analysis, the project identifies demand patterns, sales trends, and customer preferences to provide actionable recommendations for improving operations and profitability.

### Project Structure

1. **Proposal**

   - Available in [BDM PROPOSAL.pdf](BDM%20PROPOSAL.pdf).

2. **Mid-Term Submission**
   - Includes an executive summary, proof of data originality, metadata, descriptive statistics, and a detailed explanation of the analysis process.
   - Discusses initial findings and outlines the methodology for data collection, cleaning, and preparation.
   - Available in [BDM Mid Term Report.pdf](BDM%20Mid%20Term%20Report.pdf).

3. **End-Term Submission**
   - Presents comprehensive data analysis, results, and findings.
   - Includes insights into demand patterns, sales trends, profitability analysis, and recommendations for inventory and pricing strategies.
   - Available in [BDM FINAL SUBMISSION REPORT.pdf](BDM%20FINAL%20SUBMISSION%20REPORT.pdf).

4. **Final Presentation**
   - Summarizes the project with a focus on the problem statement, analysis process, and recommendations.
   - Uses data visualizations like Pareto charts, bar graphs, and pivot tables to highlight findings effectively.
   - Available in [BDM PRESENTATION.pdf](BDM%20PRESENTATION.pdf).

### Key Findings

- **Demand Patterns**: Coca-Cola emerged as the most in-demand brand, followed by PepsiCo and Parle Agro. Dabur and Bisleri showed lower demand comparatively.
- **Seasonal Variations**: Sales peak in summer and festival seasons, emphasizing the need for flexible inventory management.
- **Profitability Insights**: Coca-Cola accounted for the highest daily profit, while Bisleri had the lowest contribution to profitability.

### Recommendations

1. **Dynamic Inventory Management**: Optimize stock levels based on seasonal trends and demand patterns.
2. **Strategic Supplier Collaboration**: Adopt just-in-time ordering to avoid overstocking and reduce inventory costs.
3. **Enhanced Pricing Strategies**: Implement competitive pricing while ensuring profitability.
4. **Customer Engagement**: Introduce promotions and loyalty programs to retain high-value customers.
5. **Technology Adoption**: Use tools like Excel for advanced analytics and real-time tracking of sales and inventory.
6. **Focus on Top-Performing Locations**: Prioritize resource allocation to high-revenue locations such as Bazar and Navapura.

### Technologies Used

- **MS Excel**: For data analysis and visualization (e.g., pivot tables, Pareto charts).
- **Python**: For data cleaning, transformation, and statistical analysis.
- **Data Visualization Tools**: For generating charts and graphs to present findings effectively.
